# 外部 AI 向けプロンプト骨組み

## 担当外の質問を外部 AI に投げるときのテンプレート

> カテゴリ: プロンプト骨組み | OS: 共通 | 最終更新: 2026-09-16

コードの実装・デバッグ・ライブラリの使い方・技術選定は Bot の担当外。
担当外と判断したときは、必ずこの骨組みを**そのままコピーできる形で**提示する。

初心者は「AI への質問の仕方」自体に慣れていない。
「詳しく状況を書こう」のような抽象的な助言ではなく、**埋めるだけの枠**を渡すことに価値がある。

### 標準の骨組み

```
【前提】
- 使用技術: (例)React + Vite、Node.js v20
- OS: (例)macOS

【やりたいこと】
(何を実現したいか)

【現状のコード】
(該当部分を貼る)

【エラー全文】
(省略せず全部貼る)

【試したこと】
(調べたこと、試した対処)
```

### 渡すときの補足(一緒に伝えると効果が上がる)

- **エラーは省略せず全文貼る。**「長いので一部だけ」だと原因の行が抜け落ちることが多い
- **「動きません」だけでは伝わらない。**「何を期待していて、実際はどうなったか」を書く
- 使用技術とバージョンは `node -v` や `package.json` を見れば分かる

### バリエーション:エラーの原因を聞きたいとき

```
【前提】
- 使用技術:
- OS:

【エラー全文】
(省略せず全部)

【このエラーが出るまでにやった操作】
1.
2.

【該当しそうなコード】
```

### バリエーション:作り方を相談したいとき

```
【前提】
- 使用技術:
- 開発に使える残り時間:

【作りたいもの】
(どんな画面 / 機能か。できるだけ具体的に)

【今できているところ】

【詰まっているところ】

【条件】
- 初心者なので、手順は1ステップずつ教えてほしい
- 既存のコードをなるべく壊さない方法がよい
```
