# 知識源(knowledge/)

このディレクトリのファイルは**全文がそのままシステムプロンプトに埋め込まれる**。
ベクトル検索も RAG も使わない(SPEC §9.2)。ファイルを分けているのは検索のためではなく、
**人間が更新しやすくするため**。

## 編集ルール

1. **1チャンク = 1つの質問に答えきれる量。**巨大な資料を丸ごと貼らない
2. 各チャンク(`##` の見出し)の直下に、必ずメタデータ行を置く

   ```
   > カテゴリ: 評価軸 | OS: 共通 | 最終更新: 2026-09-16
   ```

   - カテゴリ: `評価軸` / `スケジュール` / `レギュレーション` / `環境構築` / `運営情報` / `プロンプト骨組み`
   - OS: `Windows` / `Mac` / `WSL` / `共通`(環境構築のみ)
   - 最終更新: `YYYY-MM-DD`

3. **情報を更新したら、古い記述は消す。**新旧が両方残っていると Bot が矛盾した回答を返す
4. **時刻は必ず絶対時刻で書く。**「開始2時間後」のような相対表現は誤解のもと
